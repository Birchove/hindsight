这门课是什么

你手边的这个文件夹,是 Hindsight 的一个 fork。Hindsight 是一套开源的 Agent 长期记忆系统:它给 LLM Agent 提供"记住、想起、反思"三种能力,让 Agent 不只是"带着对话历史跑",而是能随着时间学习。它在 LongMemEval 这类长期记忆基准上取得了相当领先的成绩,并且真的被用在生产环境里。

这套系统很完善,也因此很大:核心引擎若干文件动辄上万行,monorepo 里还包含 Next.js 控制台、Rust CLI、几十种框架集成、多语言 SDK。直接扎进源码,很容易迷路。

所以这门课不是"函数清单"。它做的是:把系统拆成循序渐进的章节,每一章先讲它要解决什么问题,再讲怎么解决的,然后带你对着源码读关键逻辑,最后点出容易踩的坑。对于系统里"同一件事有多种实现"的地方(比如十几种 LLM provider、好几种文档解析器),我们只精读最有代表性的一种,其余对比着讲。

📖 这门课的叙事主线

一句话:Hindsight 不是"存原文再 embed",而是把文本变成一张"可检索、可链接、可巩固"的原子事实网络。几乎所有复杂度,都是在为这张网络的"写入正确、检索高效、持续学习"服务。带着这条主线读,会顺很多。

Hindsight 一分钟

Hindsight 用"仿人记忆"(biomimetic)的方式组织 Agent 的记忆,分三类:

  • World facts(世界事实):关于外部世界的客观断言,如"炉子会变热""Alice 在 Google 工作"。
  • Experience facts(经验事实):Agent 自己的经历,如"我碰了炉子,很疼"。
  • Mental models / Observations(心智模型 / 观察):从零散事实里反思、巩固出来的更高层理解,如"用户偏好函数式编程"。

记忆存放在一个个相互隔离的 bank(记忆库) 里——可以理解成"某个用户/Agent 的一个大脑",bank 之间严格不串数据。每个 bank 还可以有一组 disposition(性格)特质(怀疑度、字面度、共情度,各 1–5),它只影响"反思"时的语气与判断,不影响检索。

图 0-1:Hindsight 的三个操作都围绕同一个记忆库。Retain 写入结构化记忆,Recall 检索,Reflect 推理;巩固(consolidation)在后台把事实提炼成观察。
  • Retain(记住):把输入交给一个 LLM,抽出事实、时间、实体、关系,规范化后落库——这是"写入通路"。
  • Recall(想起):并行跑语义 / 关键词(BM25)/ 图 / 时间四种检索,融合、重排、按 token 预算裁剪后返回——这是"读取通路"。
  • Reflect(反思):跑一个带工具的 agent 循环,按需检索记忆与心智模型,生成一段"带性格"的、有据可依的回答。

把系统跑起来(强烈建议)

读源码最好的伴侣,是一个能跑、能点断点的实例。Hindsight 自带嵌入式数据库(pg0),不装外部依赖也能起。最省事的方式是 Docker:

shell · 来自 READMEbash
export OPENAI_API_KEY=sk-xxx

docker run -it --pull always --name hindsight --restart unless-stopped \
  -p 8888:8888 -p 9999:9999 \
  -e HINDSIGHT_API_LLM_API_KEY=$OPENAI_API_KEY \
  -v hindsight-data:/home/hindsight/.pg0 \
  ghcr.io/vectorize-io/hindsight:latest

# API: http://localhost:8888   控制台 UI: http://localhost:9999

然后用官方 Python 客户端走一遍三个操作,亲手感受"输入 → 记忆 → 检索 → 反思":

quickstart.pypython
from hindsight_client import Hindsight

client = Hindsight(base_url="http://localhost:8888")

# Retain: 把信息交给系统记住(内部会抽事实、实体、关系)
client.retain(bank_id="my-bank",
              content="Alice works at Google as a software engineer")

# Recall: 检索记忆(四路并行 + 融合 + 重排)
client.recall(bank_id="my-bank", query="What does Alice do?")

# Reflect: 生成一段带性格的、有据可依的回答
client.reflect(bank_id="my-bank", query="Tell me about Alice")

想跟着源码单步调试?仓库里就有本地开发脚本(见根目录 scripts/dev/):./scripts/dev/start.sh 会同时起 API 与 Next.js 控制台;./scripts/dev/start-api.sh 只起 API(会自动读 .env)。把 .env.example 拷成 .env,填上你的 LLM provider 与 key 即可。测试大多用 MockLLM、可离线跑:

shellbash
cd hindsight-api-slim && uv run pytest tests/ -n auto   # 并行跑全部测试
cd hindsight-api-slim && uv run pytest tests/test_retain.py::test_retain_simple -v  # 跑单个

✅ 没有 LLM key 也能读

把 HINDSIGHT_API_LLM_PROVIDER 设为 none 时,系统会强制走"整块当记忆单元、不调 LLM 抽事实"的降级路径(第 11 章会讲)。跑测试则用内置的 MockLLM,完全确定性、不花钱。所以读代码本身不需要任何 key。
