What this course is

The folder you have is a fork of Hindsight, an open-source agent long-term memory system: it gives an LLM agent the ability to remember, recall, and reflect, so the agent doesn't just “run with the conversation history” but learns over time. It reports strong results on long-term-memory benchmarks (LongMemEval) and is used in production.

The system is complete, and therefore large: several core files are tens of thousands of lines, and the monorepo also holds a Next.js console, a Rust CLI, dozens of framework integrations, and multi-language SDKs. Dropping straight into the source is an easy way to get lost.

So this is not a “list of functions.” Each chapter first states the problem being solved, then how it's solved, then walks you through the real source logic, and finally flags the pitfalls. Where the system implements one thing several ways (a dozen LLM providers, several document parsers, etc.), we read the most representative one in depth and cover the rest by comparison.

📖 The narrative through-line

In one sentence: Hindsight does not “store the text then embed it” — it turns text into an atomic fact network that is retrievable, linkable, and consolidatable. Nearly all the complexity serves that network's three needs: written correctly, found efficiently, and able to keep learning. Keep that line in mind and the rest lines up.

Hindsight in one minute

Hindsight organizes memory in a biomimetic way, in three layers:

  • World facts: objective claims about the world — “the stove gets hot”, “Alice works at Google”.
  • Experience facts: the agent's own experiences — “I touched the stove and it hurt”.
  • Mental models / observations: higher-level understanding reflected and consolidated out of scattered facts — “the user prefers functional programming”.

Memories live in isolated banks — think “one brain per user/agent”; banks never leak data into each other. A bank can also carry a disposition (skepticism, literalism, empathy, each 1–5) that affects only reflection, never retrieval.

Fig 0-1: all three operations revolve around one memory bank. Retain writes structured memory, Recall retrieves, Reflect reasons; consolidation is the background loop from the bank back to itself.
  • Retain hands the input to an LLM that extracts facts, time, entities, and relations, normalizes them, and stores them — the write path.
  • Recall runs semantic / keyword (BM25) / graph / temporal retrieval in parallel, then fuses, reranks, and trims to a token budget — the read path.
  • Reflect runs a tool-using agent loop that retrieves memories and mental models on demand and produces a grounded, disposition-aware answer.

Run the system (strongly recommended)

The best companion to reading source is an instance you can run and breakpoint. Hindsight ships an embedded database (pg0), so it starts with no external dependencies. The easiest path is Docker:

shell · from the READMEbash
export OPENAI_API_KEY=sk-xxx

docker run -it --pull always --name hindsight --restart unless-stopped \
  -p 8888:8888 -p 9999:9999 \
  -e HINDSIGHT_API_LLM_API_KEY=$OPENAI_API_KEY \
  -v hindsight-data:/home/hindsight/.pg0 \
  ghcr.io/vectorize-io/hindsight:latest

# API: http://localhost:8888   Console UI: http://localhost:9999

Then exercise the three operations with the official Python client and feel “input → memory → retrieval → reflection” first-hand:

quickstart.pypython
from hindsight_client import Hindsight

client = Hindsight(base_url="http://localhost:8888")

# Retain: hand information to the system (it extracts facts, entities, relations)
client.retain(bank_id="my-bank",
              content="Alice works at Google as a software engineer")

# Recall: retrieve memories (4-way parallel + fusion + rerank)
client.recall(bank_id="my-bank", query="What does Alice do?")

# Reflect: produce a grounded, disposition-aware answer
client.reflect(bank_id="my-bank", query="Tell me about Alice")

Want to single-step the source? The repo has local dev scripts under scripts/dev/: ./scripts/dev/start.sh starts the API and the Next.js console together; ./scripts/dev/start-api.sh starts just the API (it reads .env automatically). Copy .env.example to .env and fill in your LLM provider and key. Most tests use MockLLM and run offline:

shellbash
cd hindsight-api-slim && uv run pytest tests/ -n auto   # all tests, parallel
cd hindsight-api-slim && uv run pytest tests/test_retain.py::test_retain_simple -v  # one test

✅ You can read with no LLM key at all

Set HINDSIGHT_API_LLM_PROVIDER to none and the system forces the “whole chunk is one memory unit, no LLM extraction” degraded path (covered in ch11). The tests use the built-in MockLLM — fully deterministic, no cost. So reading the code itself needs no key.
